# 공연예술 장르별 성장 양상 대시보드

> 2019년 이후 공연예술(전체와 장르별)은 얼마나 성장했고, 그 성장은 관객 수와 가격 중 무엇에서 나왔는가?

KOPIS 예매통계와 소비자물가지수로 공연예술 전체와 7개 장르의 예매액·예매수·장당 가격을 2019년과 비교하는 Streamlit 대시보드.

**배포 주소:** [https://앱이름.streamlit.app]  ← 실제 주소로 교체

## 기능
- **1. 예매액 / 2. 예매수:** 최근 12개월 합계 ÷ 2019년 연간 성장선, 월별 실제 값
- **3. 장당 가격과 물가:** 전체 장르·전체 기간 고정
  - 장당 가격 지수 vs 소비자물가 선
  - 장당 가격·물가 표 (명목 = 물가 반영 × 물가 상승)
  - 성장의 구성 표 (관객 수·가격·물가 몫)
  - 관객 수 vs 가격 사분면 차트
- **장르 비중:** 7개 장르의 분기별 비중
- **사이드바:** 장르(전체 공연 + 7개), 시작·종료 월
- **하단:** 결론 표(예매액·예매수·장당 가격·비중, 최고·최저 강조), 이 결론의 한계, 출처와 집계 기준

## 데이터
- 공연: 예술경영지원센터 공연예술통합전산망(KOPIS) 예매통계 ‘장르별통계’, 월 단위 조회 후 병합 (`data/kopis_genre_monthly.csv`)
- 물가: 국가데이터처(통계청) 소비자물가지수 총지수(2020=100), 월별 (`data/cpi_monthly.csv`)
- 기간: 2019.01~2026.10 (2026.11은 부분 자료라 제외), 조회일 2026-11-26
- 예매액 = 예매 − 취소 (예매일자 기준), 장당 가격 = 예매액 ÷ 예매수
- 물가 반영 금액 = 월별 금액 ÷ (그 달 물가지수 ÷ 2019년 평균 지수)
- 공연건수는 월별 합산 시 중복되어 미사용

## 한계
- 예매일자 기준 금액. 취소가 몰린 달은 음수 가능, 주최자 수익 아님
- 2019.6.25 공연법 개정으로 전송이 의무화됨. 그 전 집계가 불완전해 2019년 상반기가 낮고, 2019년 대비 성장에 집계 확대가 섞임
- 물가는 소비자물가지수 총지수. 공연 고유의 물가와 다를 수 있고, 장당 가격 상승에는 공연 구성 변화도 포함
- 대중음악이 7개 장르의 약 58%. 소규모 장르는 지수가 크게 흔들려 장르 간 동일 비교 부적절
- 전산 발권 공연만 집계. 수기 발권·무료 공연 제외
