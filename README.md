# 공연 음악 장르별 성장 양상 대시보드

> 2019년 이후 공연 음악 장르(대중음악·클래식·국악)는 얼마나 성장했고, 그 성장은 관객 수와 가격 중 무엇에서 나왔는가?

예술경영지원센터 공연예술통합전산망(KOPIS)의 예매통계와 소비자물가지수로, 공연 음악 장르의 예매액·예매수·장당 가격을 2019년과 비교하는 Streamlit 대시보드입니다.

**배포 주소:** [https://앱이름.streamlit.app]  ← 실제 주소로 바꾸세요

## 기능
- **성장 분해**: 명목 예매액 = 예매수 × 장당 가격(물가 반영) × 물가 요인으로 나누고, 장르별 성장 몫(로그 기준)을 표시
- **2019년 대비**: 같은 분기(월)의 2019년 값을 100으로 한 지수
- **추이**: 선택한 지표의 선 그래프, 참고 구간(코로나) 음영
- **장르 비중**: 음악 3장르 중 각 장르의 비중(분기별)
- **자료**: 선택한 조건의 표와 CSV 내려받기
- 사이드바에서 집계 단위(분기별·월별), 지표(예매액·예매수·장당 평균 가격), 금액 기준(물가 반영·명목), 장르(음악 3장르 + 뮤지컬·연극·전체 공연), 시작·종료 월을 바꾸면 숫자와 차트가 함께 바뀝니다.
- 화면 하단에 결론, "이 결론의 한계", "출처와 집계 기준"이 선택한 조건에 맞춰 표시됩니다.
- 상단 지표 카드: 예매액(물가 반영) 성장 1위, 예매수 성장 1위, 장당 가격(물가 반영) 성장 1위, 대중음악 비중

## 데이터
- 공연: 예술경영지원센터, 공연예술통합전산망(KOPIS) 예매통계 ‘장르별통계’ (월 단위로 조회해 합침). 파일 `data/kopis_genre_monthly.csv`
- 물가: 국가데이터처(통계청) 소비자물가조사, 소비자물가지수 총지수(2020=100) 월별. 파일 `data/cpi_monthly.csv`
- 기간: 2019.01~2026.10 (2026.11은 부분 자료라 제외), 조회일 2026-11-26
- 예매액 = 총 티켓예매액(예매 − 취소, **예매일자 기준**), 예매수 = 총 티켓예매수, 장당 평균 가격 = 예매액 ÷ 예매수
- 물가 반영 금액 = 월별 금액 ÷ (그 달 소비자물가지수 ÷ 2019년 평균 지수) → 2019년 물가 기준 가격
- 공연건수는 월별로 합산하면 같은 공연이 중복으로 세어져 사용하지 않았습니다.

## 실행
```
pip install -r requirements.txt
streamlit run app.py
```

## 한계
- 예매액은 공연 주최자의 수익이 아니라 티켓 판매 금액입니다. 예매일자 기준이라 취소가 몰린 달(코로나 시기)에는 값이 작아지거나 음수가 되며, 수요 감소만을 뜻하지 않습니다.
- 2019년은 공연법에 따른 수집이 본격화된 해라서 2019년 대비 성장에 집계 범위 확대가 섞여 있을 수 있습니다.
- 물가 반영은 소비자물가지수 총지수를 사용했으며 공연 티켓 고유의 물가와 다를 수 있습니다. ‘물가를 뺀 가격 상승’에는 좌석 등급·할인·공연 구성의 변화도 포함됩니다.
- 음악 3장르 중 대중음악이 약 90%를 차지해 장르 간 지수를 같은 무게로 비교할 수 없습니다.
- 전산 발권된 공연만 집계되며, 음원·스트리밍 소비가 아니라 공연 티켓 시장의 자료입니다.

## AI 사용
코드 작성·검토와 문서 초안에 Claude(Anthropic)를 사용했습니다.
