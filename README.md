# 공연 음악 장르별 예매 추이 대시보드

> 코로나 이후 공연 음악 장르(대중음악·클래식·국악)는 얼마나, 어떤 속도로 회복했는가?

예술경영지원센터 공연예술통합전산망(KOPIS)의 예매통계로, 공연 음악 장르의 순예매액을 2019년과 비교하는 Streamlit 대시보드입니다.

**배포 주소:** [https://앱이름.streamlit.app]  ← 실제 주소로 바꾸세요

## 기능
- **2019년 대비**: 같은 분기(월)의 2019년 값을 100으로 한 지수, 장르별 저점과 회복 분기
- **추이**: 선택한 장르의 순예매액(순예매수) 선 그래프, 참고 구간 음영
- **장르 비중**: 음악 3장르 중 각 장르의 비중(분기별)
- **자료**: 선택한 조건의 표와 CSV 내려받기
- 사이드바에서 집계 단위(분기별·월별), 지표(순예매액·순예매수), 장르(음악 3장르 + 뮤지컬·연극·전체 공연), 시작·종료 월을 바꾸면 모든 숫자와 차트가 함께 바뀝니다.
- 화면 하단에 결론, "이 결론의 한계", "출처와 집계 기준"이 선택한 조건에 맞춰 표시됩니다.
- 상단 지표 카드: 2019년 대비 1위, 저점이 가장 깊은 장르, 가장 먼저 회복한 장르, 대중음악 비중

## 데이터
- 출처: 예술경영지원센터, 공연예술통합전산망(KOPIS) 예매통계 ‘장르별통계’ (월 단위로 조회해 합침)
- 기간: 2019.01~2026.10 (2026.11은 부분 자료라 제외), 조회일 2026-11-26
- 순예매액 = 총 티켓예매액(예매 − 취소, **예매일자 기준**), 순예매수 = 총 티켓예매수
- 파일: `data/kopis_genre_monthly.csv`
- 공연건수는 월별로 합산하면 같은 공연이 중복으로 세어져 사용하지 않았습니다.

## 실행
```
pip install -r requirements.txt
streamlit run app.py
```

## 한계
- 예매일자 기준의 순예매액이라 취소가 몰린 달(코로나 시기)에는 값이 작아지거나 음수가 되며, 수요 감소만을 뜻하지 않습니다.
- 2019년은 공연법에 따른 수집이 본격화된 해라서 2019년 대비 증가에 집계 범위 확대가 섞여 있을 수 있습니다.
- 음악 3장르 중 대중음악이 약 90%를 차지해 장르 간 지수를 같은 무게로 비교할 수 없습니다.
- 전산 발권된 공연만 집계되고, 금액은 물가를 반영하지 않은 명목값이며, 음원·스트리밍 소비가 아니라 공연 티켓 시장의 자료입니다.

## AI 사용
코드 작성·검토와 문서 초안에 Claude(Anthropic)를 사용했습니다.
